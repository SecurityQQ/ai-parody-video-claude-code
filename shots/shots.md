# Shots and how each is made

Routing rule from the previz-to-picture guide, first yes wins: exact things (text, faces from photos, timing to the
voice) go to code; a camera move that must be obeyed gets the blockout as a video reference; the rest is a prompt and
a start frame.

| Shot | Film time | What | Made by | Why |
|---|---|---|---|---|
| sh010 | 0.00-3.00 | Atrium, a small figure crosses the bridge | AI video from a still (Seedance 2.5, 480p) | Nothing exact: locked camera, one walker, no face |
| sh020 | 3.00-5.58 | Floor-height tracking shot of sneakers | AI video with the blockout as @video1 | The camera path is the shot |
| sh030 | 5.58-21.13 | Dark corridor: the reveal, "Not you", the jacket | Code (HyperFrames) over a generated still | The faces are photos; every beat is cut to a word |
| sh040 | 21.13-24.54 | Daylight corridor: "Good morning!" | Code over a generated still | Same |
| sh050 | 24.54-36.33 | Closer: the card folds, the tags, Jensen leans in | Code over the same still | Exact text and a prop that must fold on a word |
| sh060 | 36.33-40.83 | End card | Code | Text |

No generative model was given a photo of either man, and no model drew any text.
